ТЯПКИН СЕРВИС — сайт сервисного центра по ремонту ноутбуков

Структура:
- index.html — главная страница
- advantages.html — преимущества
- prices.html — цены
- about.html — о нас и контакты
- css/style.css — пользовательские стили
- js/main.js — обработка формы и небольшие сценарии

Запуск:
1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Для корректного отображения нужен доступ к интернету, так как Bootstrap, Bootstrap Icons и шрифты подключены через CDN.

Важно:
Форма заявки демонстрирует пользовательский сценарий и проверку полей, но не отправляет данные на сервер. Для реального получения заявок нужно подключить backend, CRM или почтовый сервис.
Телефон, почта, график и адрес указаны как демонстрационные контактные данные — замените их на реальные перед публикацией.
